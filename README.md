# ✨ Glow — AI Skin Intelligence

**Upload a selfie. Get a full AI skin report in ~30 seconds — 14 concern scores with visual masks, skin age, Fitzpatrick sun type, exact skin tone, a personalized routine, and progress tracking.**

> Built for the **YouCam API Skin AI & Apparel VTO Hackathon** — uses 3 YouCam APIs (skin-analysis · skin-tone-analysis · fitzpatrick-scale-analyzer).

## 🎯 Problem
Skincare is a $150B+ industry built on guesswork: generic quizzes, self-reported skin types, expensive dermatologists, and no way to know if a product is working.

## 💡 Solution
**Glow** turns any phone camera into a skin-analysis tool:
1. **📸 Upload a selfie** → 3 YouCam AI analyses run in parallel
2. **📋 Report** — overall skin score, skin age, 14 concern scores (0–100) with detection masks showing *where* each concern is, Fitzpatrick type (UV reactivity), exact skin tone + eye/lip/brow/hair colors
3. **🧴 Routine** — personalized AM/PM plan generated by rules from your *actual* scores (higher concern = prioritized step)
4. **📈 Progress** — every scan is saved; re-scan anytime and watch scores improve

## ⚙️ Tech stack (deliberately simple — every choice explainable)
| Layer | Choice | Why |
|-------|--------|-----|
| Frontend | React 18 + Vite + TypeScript | Reusable components, fast builds |
| Styling | Plain CSS (custom warm-editorial system) | No framework dependency |
| "Database" | localStorage (MVP) | Zero-setup history; Supabase-ready schema in docs/DATABASE.md |
| AI | YouCam v2 APIs (browser-direct, CORS-open) | The hackathon API; verified live |
| Deploy | GitHub Pages | Free subdomain, static |
| Testing | Vitest (5 tests) + headless-Chromium E2E | Test everything |

## 🧱 Architecture
```
Browser (React) ──► YouCam API (3 parallel tasks, CORS-open, key via env)
      │                        │
      │                        └─► skin-analysis (14 concerns, 16u)
      │                        └─► skin-tone-analysis (20u)
      │                        └─► fitzpatrick-scale-analyzer (10u)
      ▼
localStorage history ◄── results → routine engine → UI
```

## 🛠️ Getting started
```bash
npm ci
cp .env.example .env   # add VITE_YOUCAM_KEY (https://yce.makeupar.com/api-console)
npm run dev            # http://localhost:5373
```
Without a key the app runs in **demo mode** (sample data, clearly labeled) — the demo never breaks.

## 🔌 API usage
| Endpoint | Method | Body | Cost |
|----------|--------|------|------|
| `/s2s/v2.0/file/{slug}` | POST | `{files:[{content_type,file_name,file_size}]}` | free |
| (presigned URL) | PUT | image bytes | free |
| `/s2s/v2.0/task/skin-analysis` | POST | `{src_file_id, dst_actions:[14], format:"json"}` | 16u |
| `/s2s/v2.0/task/skin-tone-analysis` | POST | `{src_file_id, format:"json"}` | 20u |
| `/s2s/v2.0/task/fitzpatrick-scale-analyzer` | POST | `{src_file_id, version:"1.0"}` | 10u |
| `/s2s/v2.0/task/{slug}/{task_id}` | GET | poll until `success` | free |

**~46 units per full scan** → ~21 scans per 1,000 hackathon units. Errors/polls are free.
